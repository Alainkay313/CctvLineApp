# CCTV Line Android App

Android app for CCTV Line website.

Website: https://cctvline.co.uk

## Features

- Android WebView app
- Loads CCTV Line website inside the app
- Supports shopping, account, cart, quote and kit builder pages
- Handles external links such as phone, email, WhatsApp and maps
- Ready for APK build using GitHub Actions

## Tech Stack

- Kotlin
- Android WebView
- Gradle
- GitHub Actions
